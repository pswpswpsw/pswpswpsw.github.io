How anonymity works here. This page has no analytics. The form sends your text to a small script that stores only what you write and the date (not the time). The script does not read or store your IP address, browser information, or e-mail. The request does pass through Google's servers, as with any Google-hosted service. The source code is public, so you can check this. Specific details (a particular meeting, your writing style) can still identify you, so keep that in mind.
